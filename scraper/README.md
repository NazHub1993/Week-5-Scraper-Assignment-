# Books to Scrape

## Target Classification

This project uses Books to Scrape as the scraping target.

Books to Scrape is a public practice sandbox designed for learning and testing web scraping.

### Scope

The scraper will collect data from only the first three catalogue pages.

It will discover the book links from those catalogue pages and visit the corresponding book detail pages.

### Data Collected

For each book, the scraper will collect:

- Title
- Product URL
- Price
- Availability
- Rating
- Description
- Source page
- Fetch timestamp

### Why This Target Is Appropriate

Books to Scrape is specifically provided as a practice sandbox for scraping, making it an appropriate target for this assignment.

I will not reuse this code on another site without checking its rules and terms first.
